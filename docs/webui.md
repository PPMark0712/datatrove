# WebUI 数据筛选平台

基于 Gradio 的 Web 界面，提供上传数据 → 配置流水线 → 查看分布 → 下载结果的完整流程。支持本地和远程服务器部署。

## 安装

```bash
# 本地（仅 FCD，无 GPU）
pip install -e ".[webui]"

# 服务器（全功能，含 CDF-GC）
pip install -e ".[webui,gpu]"
```

## 启动

```bash
cd webui
bash run.sh
```

浏览器访问 `http://localhost:7860`（或 `http://服务器IP:7860`）。

### 配置

编辑 `webui/run.sh`：

```bash
# 账号密码（格式 "用户名:密码"，多个用逗号分隔）
export WEBUI_AUTH="admin:datatrove2024"

# 服务端口
export WEBUI_PORT=7860

# GPU 设备（CDF-GC 需要，按需打开）
# export CUDA_VISIBLE_DEVICES=0,1,2,3
```

### 远程访问

- 直接访问：确保服务器防火墙放行端口
- SSH 隧道：`ssh -L 7860:localhost:7860 服务器`，然后访问 `localhost:7860`

## 功能介绍

### Tab 1：数据上传

| 功能 | 说明 |
|------|------|
| 上传文件 | 支持多个 `.jsonl` 文件拖放上传 |
| 服务器目录 | 填写服务器上的目录路径，自动 glob `*.jsonl` |
| 任务 ID | 留空自动生成；填写已有 ID 可恢复之前的任务 |
| 数据预览 | 上传后展示前 10 条数据的 id 和 text 摘要 |

上传后系统会自动将数据 split 为每文件最多 5000 行，便于后续并行处理。

### Tab 2：流水线配置

可选择以下处理步骤（按勾选顺序串联执行）：

**数据清洗**
- 语言过滤 + 质量过滤 + MinHash 去重
- 参数：目标语言（逗号分隔，如 `zh,en`）

**FCD 打分**（英文，纯 CPU）
- 计算每篇文档的词汇难度分数
- 可调参数：`freq_scaling_factor`、`w_f`、`noun_weight`

**CDF-GC 打分 + 采样**（中文，需 GPU）
- 完整的 GC 计算 + CDF 采样流水线
- 可调参数：采样率、Tokenizer 路径、LTP 模型路径、GPU 设备、每 GPU workers 数

**采样**（基于 FCD 分数，需先启用 FCD）
- 三种策略可选：CDF / Hard / Random
- 可调参数：采样率、采样单位（doc/token）

**执行控制**
- 可设置并行 workers 数（1-64）
- 点击「开始处理」异步执行，不阻塞页面
- 点击「刷新状态」查看进度和日志

**分数分布可视化**
- 刷新状态时自动绘制已有分数的 PDF（概率密度）和 CDF（累积分布）图
- 也可手动选择分数类型（FCD / GC）绘制
- 图表包含 n、mean、std、median 统计标注

**结果下载**
- 处理完成后点击「下载结果」获取 zip 压缩包
- 输出文件按每文件最多 5000 行 merge

### Tab 3：任务管理

| 功能 | 说明 |
|------|------|
| 任务列表 | 查看所有历史任务的状态（创建/运行/完成/错误） |
| 断点续传 | 填入任务 ID + 设置 workers 即可恢复运行，框架自动跳过已完成步骤 |

## 处理流程

```
上传 JSONL
    │
    ▼
Split（每文件 ≤5000 行）
    │
    ▼
[可选] 数据清洗（语言过滤 → 质量过滤 → 去重）
    │
    ▼
[可选] FCD 打分 → [可选] 采样（CDF/Hard/Random）
    │
    ▼
[可选] CDF-GC 打分 + CDF 采样
    │
    ▼
Merge 输出（每文件 ≤5000 行）
    │
    ▼
打包 zip 供下载
```

## 数据溯源

输出数据中的 `id` 字段格式为 `原始文件路径/行号`，可追溯到原始输入文件和行。
