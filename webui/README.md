# 领域大模型训练数据筛选与质量评估平台

## 启动

在仓库根目录运行（Python 3.10+，Gradio 6.26.x）：

```bash
python -m pip install -e ".[webui]"
python -m nltk.downloader -d webui/.cache/nltk_data \
  wordnet stopwords punkt_tab averaged_perceptron_tagger_eng
WEBUI_AUTH="1:1" python webui/app.py
```

访问 <http://localhost:7860>。`WEBUI_AUTH` 使用 `用户名:密码` 格式，多个账号以逗号分隔；未设置时使用 `admin:datatrove2024`。认证由 Gradio 服务端执行。默认仅监听本机；需要远程访问时设置 `WEBUI_HOST`。端口可由 `WEBUI_PORT` 指定。关闭认证仅适用于本机测试。

数据清洗还依赖 datatrove 的语言识别模型、分词器和过滤器依赖；首次运行可能下载模型。FCD 所需词典已包含在仓库中，NLTK 语料使用上述命令安装。可用 `NLTK_DATA` 指向已有语料目录。

## 操作流程

1. **添加数据集**：上传 JSONL、包含 JSONL 的 ZIP，或指定服务器目录。每行是 JSON 对象，必须有非空字符串 `text`，`id` 和 `metadata` 可选。导入时校验全部记录；ZIP 内同名文件会自动编号，避免覆盖。
2. **预览**：选择左侧数据集，查看文件数或修改名称。预览默认收起，不读取记录；展开加载前 20 行，在表格内下滑接近底部时每次追加 20 行，也可点击“加载下 20 行”。至多预览 5 页、100 行，尚有内容时用省略号提示。表格显示两行摘要，点击单元格才读取完整正文；元数据使用独立 JSON 代码块、4 空格缩进，正文和元数据均可复制。收起或切换数据集、任务后清空预览和详情，再次展开从前 20 行开始。
3. **创建任务**：点击当前列表末尾的“新建任务”。平台复制当前数据集作为任务输入，后续修改原数据集不会改变已有任务的输入副本。
4. **配置并运行**：默认启用中英文清洗。任务完成后自动展示结果；运行期间可切换查看其他任务，后台任务继续运行。当前服务只允许一个流水线任务同时执行。
5. **结果**：查看输入、语言过滤、质量过滤、去重与最终输出的记录数；结果预览同样按需展开，最多加载 100 行。可下载完整 JSONL 压缩包或保存为新的数据集，预览上限不影响下载和保存。全部被过滤时显示 0 条，不会把中间文件当作最终结果。

## 配置与恢复

- “开始处理 / 重新运行”使用当前表单配置，重新计算并清理该任务旧的中间缓存和输出。
- “继续运行”适用于失败或停止的任务，使用上次保存的配置与已完成阶段缓存；表单修改不会改变续跑配置。
- 配置草稿按任务保留在当前会话中；切换任务、刷新状态和重命名不会覆盖草稿。刷新整个网页后恢复上次运行的配置。
- 未启用步骤的参数不可编辑，配置区会提前提示语言和步骤冲突。任务运行时配置锁定，完成或停止后恢复。
- 结果页对待运行、运行中、停止和失败分别显示说明；只有完成任务才显示统计，零输出时隐藏空预览并禁用保存。纯清洗任务不显示分数分布。
- “停止”终止任务的实际子进程，完成退出后状态变为“已停止”。服务重启后遗留的运行状态会标记为停止。
- 删除任务需要二次确认，原始数据集不会被删除。
- 添加数据集弹窗支持 Escape 关闭和键盘焦点循环；弹窗打开时底层页面不可操作，关闭后焦点返回添加按钮。

## 打分与采样范围

- **FCD**：面向英文，支持 CPU。与清洗一起使用时仅保留 `en`。分数写入输出记录的 `metadata.fcd_score`。结果页列出采样前打分数量；分布图统计全部已打分记录，在分数范围内划分 100 个等宽桶，展示概率密度曲线和累计分布曲线，不绘制柱形。密度为桶内概率除以桶宽，CDF 累加同一组桶的概率。
- **CDF-GC**：面向中文，需要 CUDA GPU、Tokenizer 文件和 LTP 模型。与清洗一起使用时仅保留 `zh`。当前本机没有完成 GPU 端到端验证；界面会在缺少资源时明确报错。GC 分布按归一化分量展示。
- 两种打分方法请分别创建任务，避免将中文交给英文 FCD 处理。
- 平台采样当前支持按文档数计算的 `cdf`、`hard` 和 `random` 策略，需要启用 FCD。按 token 采样需要额外的逐文档 token 计数，当前界面不提供此选项。
- **Hard**：通过单选项选择。在每个输入分片内按 FCD 分数从高到低选择 `floor(分片文档数 × 采样率)` 条，输出保留输入顺序。多分片时不等价于全数据集全局 Top-K。采样率相对于采样前记录数，结果摘要中的总保留率相对于原始输入。

## 文件位置

| 内容 | 路径 |
|---|---|
| 数据集 | `webui/workspace/<名称>/` |
| 任务输入副本 | `webui/tasks/task_N/input/` |
| 任务配置、状态、日志 | `config.json`、`status.json`、`task.log` |
| 最终 JSONL 输出 | `webui/tasks/task_N/output/` |
| 下载压缩包 | `webui/tasks/task_N/result_task_N.zip` |
| 分阶段结果及被过滤记录 | `webui/tasks/task_N/work/data_clean/` |
| NLTK 本地语料 | `webui/.cache/nltk_data/` |

运行数据、缓存和 `webui/test_data/` 均已排除出 Git。旧版本生成的任务结果不会被自动重写；需要重新运行才能应用最终结果收集修复。
